# Hints

## Hint 1

Put the claim in an approval tray, retaining its folder number, then continue when the adjuster returns a signed decision. Compare the first differing field with the task's required behavior.

## Hint 2

A rejected proposal must not become an approved result. Inspect the operation that owns this update or routing choice.

## Hint 3

The reference contract uses this operation: "approved" if response["approved"] else "rejected". Check every boundary input after the repair; a default-case pass alone is insufficient.
