# Hints

## Hint 1

A desk notebook disappears with the desk; a closed archive file can be reopened by the next shift. Compare the first differing field with the task's required behavior.

## Hint 2

A restarted process must merge the new note with stored notes. Inspect the operation that owns this update or routing choice.

## Hint 3

The reference contract uses this operation: notes: Annotated[list[str], operator.add]. Check every boundary input after the repair; a default-case pass alone is insufficient.
