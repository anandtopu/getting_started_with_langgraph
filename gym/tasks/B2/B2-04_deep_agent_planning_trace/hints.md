# Hints

## Hint 1

A visible investigation checklist helps organize work, but checked boxes still need supporting records. Compare the first differing field with the task's required behavior.

## Hint 2

Keep task progress consistent with the supplied status. Inspect the operation that owns this update or routing choice.

## Hint 3

The reference contract uses this operation: "status": case["first_status"]. Check every boundary input after the repair; a default-case pass alone is insufficient.
