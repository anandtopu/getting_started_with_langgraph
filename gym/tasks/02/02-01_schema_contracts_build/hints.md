# Hints

## Hint 1

A form template, a filled form object, and a clerk checking the form are different services. Compare the first differing field with the task's required behavior.

## Hint 2

A successful validation node must record its result. Inspect the operation that owns this update or routing choice.

## Hint 3

The reference contract uses this operation: return {"status": "validated"}. Check every boundary input after the repair; a default-case pass alone is insufficient.
