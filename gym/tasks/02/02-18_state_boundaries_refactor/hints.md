# Hints

## Hint 1

The customer copy of a file omits the adjuster's internal worksheet. Compare the first differing field with the task's required behavior.

## Hint 2

A refactored input boundary must still supply the fields its nodes read. Inspect the operation that owns this update or routing choice.

## Hint 3

The reference contract uses this operation: input_schema=Input. Check every boundary input after the repair; a default-case pass alone is insufficient.
