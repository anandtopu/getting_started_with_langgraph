# Hints

## Hint 1

A referral changes the responsible desk and includes both the referral form and its receipt. Compare the first differing field with the task's required behavior.

## Hint 2

Address the parent graph when handing off to its specialist. Inspect the operation that owns this update or routing choice.

## Hint 3

The reference contract uses this operation: graph=Command.PARENT. Check every boundary input after the repair; a default-case pass alone is insufficient.
