# Hints

## Hint 1

A process map and a dated case file can diagnose a wrong desk assignment even without a visual control room. Compare the first differing field with the task's required behavior.

## Hint 2

Debug the supplied claim amount rather than a substituted value. Inspect the operation that owns this update or routing choice.

## Hint 3

The reference contract uses this operation: "amount_cents": case["amount_cents"]. Check every boundary input after the repair; a default-case pass alone is insufficient.
