# Hints

## Hint 1

A tracking slip names the case and desk, without photocopying the customer's private paperwork. Compare the first differing field with the task's required behavior.

## Hint 2

Do not report a successful node as failed during logging refactors. Inspect the operation that owns this update or routing choice.

## Hint 3

The reference contract uses this operation: "status": "ok". Check every boundary input after the repair; a default-case pass alone is insufficient.
