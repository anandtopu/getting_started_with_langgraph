# Reference design review

Deductible and quote arithmetic need plain Python: bounded inputs produce a direct result. The document checklist and description classification have known stages, so a workflow keeps their contracts explicit. An open policy investigation may need an agent to select among read-only tools; a fixed question would still favor a simpler lookup. An approval wait needs persisted state and an explicit human decision, so a workflow fits.

LangGraph owns workflow state and resumable execution. LangChain can supply a tool-using agent. LangSmith can help observe or host it but is optional to this course. No component may treat free-text approval as authorization. This review earns 2/2 in each rubric category for these assumptions, but deployment scale and policy details would need separate evidence.
