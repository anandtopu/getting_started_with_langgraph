# Self-review rubric

Score each category 0 (absent), 1 (partial), or 2 (clear and justified).

1. Simplicity: calculations stay simple, and any agent has a concrete need for dynamic choices.
2. State and waits: durable information and human decisions are identified explicitly.
3. Responsibilities: distinguish plain Python, graph runtime, agent construction, and optional observability.
4. Evidence and limits: explain assumptions, risks, and a reasonable alternative for each scenario.

Aim for at least 6/8, with no zero. Record the score and reasoning in your design file. Passing code tests checks the shape of the answer, not its merit.
