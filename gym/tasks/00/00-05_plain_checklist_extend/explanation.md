# Why it works

Normalization must happen before missing-field checks. A dictionary copy preserves the caller's input. Check explicit missing values rather than treating zero as false. A duplicate is recognized first, so this task never starts another intake for it. The trace names the actual sequence of responsibilities. Reasons add observability without changing the routing contract. Common wrong answers overwrite identity, reverse the missing-list condition, or omit duplicate precedence. No model is useful for these fixed rules.
